# 🖥️ PC Helper

A lightweight Windows utility toolkit built with Python.

## v0.5.0

PC Helper is becoming a compact Windows control center:

- ⚡ Live CPU usage
- 🧠 Live RAM usage
- 💾 Live disk usage
- 🧹 Temporary file scanner and cleanup
- 🌐 Network diagnostics
- 📡 Ping connectivity test
- 🔄 DNS cache flush
- 💻 Local IP detection
- 🛠️ Windows tools launcher
- 📋 Task Manager
- 🔧 Device Manager
- ⚙️ Control Panel
- ⌨️ Command Prompt
- 💻 PowerShell
- 🔩 Services
- ℹ️ System Information
- 🧹 Disk Cleanup
- 🔄 Windows Update
- 🌙 Dark desktop UI

## Run locally

```bash
pip install -r requirements.txt
python main.py
```
