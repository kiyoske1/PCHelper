# 🖥️ PC Helper

A lightweight Windows utility toolkit built with Python.

## v0.1.0

Current release provides a simple dark GUI with live system information:

- CPU
- RAM
- Windows version
- System architecture
- Hostname
- Refreshable system information

## Run locally

```bash
pip install -r requirements.txt
python main.py
```
