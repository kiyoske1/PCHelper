# 🖥️ PC Helper

A lightweight Windows utility toolkit built with Python.

## v0.2.0

PC Helper now includes a live system monitor that updates every second:

- ⚡ CPU usage
- 🧠 RAM usage
- 💾 Disk usage
- 💻 CPU, Windows and system information
- 🌙 Dark desktop UI

## Run locally

```bash
pip install -r requirements.txt
python main.py
```
